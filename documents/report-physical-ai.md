# 피지컬 AI 기술분야 동향·전략 분석 리포트

> 상태: 초기 분석 기준본 · 실시간 자료 연동 전

## 정책결정자용 요약

피지컬 AI는 AI가 물리환경을 인식하고 판단하며 행동하는 기술군이다. 휴머노이드·자율제조·자율주행은 기술요소가 겹치지만 시장·규제·실증 조건이 다르므로 별도 분석 단위로 유지해야 한다.

- 핵심 판단: 공통 기반과 세부 시장을 분리한 포트폴리오가 필요하다.
- R&D 시사점: 로봇 파운데이션 모델, 센서·구동계, 시뮬레이션, 안전성 검증이 중요하다.
- 시장진출: 수요기업 현장 실증과 공공 테스트베드를 연계한다.
- 인재: AI·로봇·제어·현장공정·안전을 연결하는 인력이 필요하다.

## 1. 세부 분석축

### 휴머노이드

하드웨어·구동계·센서, embodied AI, 인간-로봇 상호작용, 조작·보행, 안전성과 사업화를 분석한다.

### 자율제조

산업용·협동로봇, 제조공정 자율화, 디지털 트윈, 지능형 생산·물류, 수요기업 실증을 분석한다.

### 자율주행

인지·판단·제어, 차량·도로 협력, 센서·컴퓨팅, 시뮬레이션, 안전성·법·보험을 분석한다.

## 2. 정부 R&D 포트폴리오 시사점

공통 AI·센서·시뮬레이션 기반과 분야별 실증·규제 연구를 분리하여 투자하고, 연구성과가 현장 데이터와 연결되도록 설계한다.

## 3. 시장진출·사업화 방안

제조·물류·돌봄·재난·모빌리티 수요를 기준으로 실증 대상을 선정하고, 안전성 검증·보험·조달·수요기업 공동투자를 연계한다.

## 4. 우선 정책대안

1. 피지컬 AI 공통 시뮬레이션·평가 인프라
2. 자율제조 중심 수요기업 공동실증
3. 휴머노이드 안전·표준·데이터 프로그램
4. 자율주행 실증·검증·규제 연계
