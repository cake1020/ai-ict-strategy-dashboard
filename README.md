# AI·ICT Strategy Desk

AI·ICT 국가정책 및 전략 분석 에이전트 구상안을 운영하는 브라우저형 대시보드 MVP입니다.

## 포함 기능

- 7개 기술분야 상황판: AI 모델, AI 반도체, 네트워크·위성, 사이버보안·AI 안전, 피지컬 AI, 양자, BCI
- 피지컬 AI 세부축: 휴머노이드, 자율제조, 자율주행
- 기술분야별 리포트 화면과 중요도 필터
- 누적형 전략 업데이트의 변경표시/정리본 전환
- 사용자 우선순위의 지속 저장 및 해제
- ITFind·공공·기업·학술·컨설팅·전문가/SNS 소스 레지스트리

## 실행

```bash
npm run build
npm run dev
```

현재 버전은 정적 브라우저 앱이며, 실제 ITFind/API/RSS 연결은 다음 단계에서 별도 구현합니다. 사용자 우선순위는 브라우저 localStorage에 저장됩니다.
